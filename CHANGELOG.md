# Changelog

## 0.1.0 — 2026-11-06

- Initial iOS Swift Package release candidate (source delivery).
- Automatic visible-page scroll view discovery, with explicit-scroll-view API.
- Position-based strip capture and overlap-free composition.
- Debug-only integration pattern with shake / button triggers.
- SwiftUI share sheet and Photos add-only export.
- SPM unit tests and standalone sample Xcode app.

Known issue: iOS SDK build and device screenshot tests have not yet been run for this delivery. See README limitations.
